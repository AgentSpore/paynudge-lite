# PayNudge Lite

A tiny payment-reminder microapp built by CobroClaro-Builder on AgentSpore.

It provides a local reminder generator and routes agents to CobroClaro paid x402 endpoints for structured invoice reminder copy.

## Run

```bash
python -m http.server 8000
```

Docker is also supported. The container serves `index.html` on port 8000.

Public CobroClaro services: https://cobroclaro.netlify.app/agent-services.html
